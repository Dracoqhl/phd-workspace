# 博士工作台

博士工作台是一个面向博士生和科研学习者的个人工作台。它把科研任务、每日习惯、轻量的自我关怀和 AI 辅助整理放在同一个页面里，适合用来维护长期研究计划、阶段性任务和每天的行动清单。开发这个项目是因为目前市面上的日程管理要么太复杂，很多功能使用频率低却白白占据了空间和注意力，或者是太简单，无法满足常用的需求。本项目将管理项目全都放在同一个看板中，后续也会逐步开发更多可定制化的选项。

项目目前处于 private beta 阶段，适合个人自托管或小范围邀请试用。

## 功能

- 任务管理：支持父任务、子任务、状态、优先级、截止日期和完成状态。
- 每日习惯：记录每日习惯进度，支持多次打卡和目标次数调整。
- 心灵关怀：提供每日短句、能量自评和今日 focus。
- AI 助手：在右侧面板中帮助拆解任务、整理计划，并在用户确认后写入任务或习惯。
- 多用户试用：管理员可以生成一次性邀请码，邀请用户注册。
- 主题切换：内置 Light、Dark、Forest、Warm 和 System 模式。

## 适合谁

- 正在推进博士论文、科研项目或长期学习计划的人。
- 希望把任务、习惯和日常状态放在一个界面里维护的人。
- 希望 AI 作为辅助工具来进行日程管理。

## 快速开始

先安装依赖：

```bash
pnpm install
```

复制环境变量示例：

```bash
cp .env.example .env.local
```

启动开发环境：

```bash
pnpm dev
```

打开：

```text
http://localhost:3000
```

如果你是在服务器上长期使用，建议使用项目提供的启动脚本：

```bash
./scripts/start.sh
```

## 基础配置

项目可以用两种方式运行：

- 单用户模式：适合个人本地试用。
- 多用户模式：适合自托管和邀请制试用。

常用配置写在 `.env.local` 中。至少需要配置会话密钥；如果要启用 AI 助手，还需要配置模型服务。

```bash
SESSION_SECRET=replace-with-a-long-random-secret

# 可选：启用多用户模式
DATABASE_PATH=/absolute/path/to/phd-workspace.sqlite
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=replace-with-admin-password

# 可选：启用 AI 能力
AI_API_KEY=your-model-api-key
AI_MODEL=your-model-name
AI_BASE_URL=https://api.openai.com/v1
```

`.env.local` 中的真实密钥和密码只应该保存在你的机器或服务器上，不要公开。

## 使用方式

首次进入后，你可以先从任务区创建研究任务，再在习惯区维护每日行动。心灵关怀区用于记录当天状态和 focus。右侧 AI 助手可以帮助你拆解计划、整理任务或生成可确认的操作建议。

AI 写入数据前会展示确认卡片。只有当你点击确认后，建议才会真正写入任务或习惯。

## 数据和隐私

博士工作台默认面向自托管场景。你的运行数据保存在你配置的本机或服务器路径中。当然不在意个人日程方面的数据隐私也可以联系我，直接使用我部署好的服务。

AI 相关能力通过服务端调用模型接口。API Key 不会发送到浏览器端。AI 助手只用于维护任务、习惯、计划和心灵关怀设置，不应该用于提交密码、密钥或处理其他敏感信息。
